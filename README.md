# 3.0 — 公网中继＋MCP

本分支只交付一份对应源码和每个已有系统各一个单文件夹运行包。1.0～4.0 是仓库分类号。

- [源码](source/)：应用实现及其依赖锁文件、构建和使用资料；测试和第三方依赖不冒称应用源码。
- [运行包及校验](release/)：完整解压到独立目录，保留整个目录。

- [linux-x64.tar.gz](release/linux-x64.tar.gz)
- [windows-x64.zip](release/windows-x64.zip)

Windows 本次仅完成包结构、源码与依赖核对，未做 Windows 实机启动验收。 运行包包含完整稳定中继、MCP 实现和生产依赖；不交付配对 GUI 预览包。

Linux 2.0、3.0、4.0 已分别完成本次真实公共 MQTT 中继近远端测试；4.0 完成 11 项配对及自动恢复检查，3.0 完成 54 次 MCP 集成调用。按用户要求不执行一小时验收。具体最终下载包的检查记录见 release/MANIFEST.json。

不要复制或上传运行后生成的密钥、配对状态、连接报告和日志。
