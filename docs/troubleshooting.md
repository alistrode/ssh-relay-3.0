# 连接排查

先读取目标平台的 `.agents/skills/connect-*/SKILL.md`，按其中指引检查环境网络策略、正常 HTTPS 代理和 CA 信任。不得绕过明确的网络拒绝。

连接成功必须依次确认：中继订阅成功、收到认证 peer、SSH 严格主机指纹校验通过、`whoami` 与 `hostname` 确认用户电脑。端口监听、PID 或订阅成功本身不能证明已连接远端；禁止用云端自测代替真实用户电脑。

45 秒未收到认证 peer 时，检查远端窗口是否仍运行、连接块是否对应当前实例，以及仓库外私密状态中的 `near.log`。不要公开凭据和未经脱敏的日志。只停止自己启动的近端进程；重启近端后重新验证身份。

不同云任务即使工作路径相同，也不代表共享文件、密钥或进程。新 AI 应通过完整连接块和完整 skill 导入，不猜测旧状态路径。

下载或更新仓库前确认 GitHub 账户有权限。缺少认证与分支不存在是两种错误。历史内容保存在 `archive/legacy-mcp-ssh-manager-2026-10-16`；当前主分支只维护公网 SSH 中继。
