# 配对式增强版验收

本记录明确区分应用实现、云端公网实测、真实 Windows 原连接、桌面交互与开机验证。最终冻结源码的一小时公网测试已通过；中断的预检不计作通过。

## 已有实际证据

- 认证加密与存储：错误配对码、篡改、过期及超长数据拒绝，128 位码格式，0600 与原子替换，符号链接拒绝通过。
- 公网生命周期七项：首次配对并实际 SSH 核验；第二独立配对不重置第一条；重复管理实例拒绝；近端重启保留配对；远端工作进程崩溃恢复两条近端；远端管理进程重启恢复所有链路；撤销全部授权、阻止旧访问及重新配对通过。
- 连续崩溃：真实结束四次本测试工作进程，第四次等待已递增；稳定窗口前不会因短暂 ready 清零计数。
- 中继断线：仅切断测试近端的代理连接约 12 秒；仍经原正常代理访问公共 WSS。约 20 秒恢复，身份与配对保留；实际重试定时与日志安排的最大偏差 6 毫秒。
- 原有可靠传输七项故障注入：PUBACK 与对端交付分离、丢包、ACK 丢失、乱序去重、reset 丢失、容量保留、持续丢失明确失败通过。该项使用内存 MQTT 和真实回环 TCP，不冒充公网。
- MCP 配对报告接入：实际发现 37 个工具、5 个提示词和 1 个资源，执行身份探测及 32 KiB 文件往返成功。工具发现不代表全部业务通过；数据库和计划任务依赖的实际业务仍未验收。
- Linux 便携包的官方组件校验、解压和首次准备通过。没有桌面的云端无法证明系统托盘或真实桌面双击体验。

## 最终一小时窗口

以真实单调时钟运行至少 3600 秒；并行活跃/空闲 SSH、周期性身份探测和 64 KiB 双向 SFTP 核验。SSH 客户端保活关闭；近远端经过正常 HTTPS 代理和公共 EMQX WSS，不走直接近远端 TCP 捷径。实际来源为云端隔离 Linux 近远端，不是用户 Windows 电脑。

实际运行 3623.700 秒，108 次 SSH 身份探测、54 次 64 KiB 文件往返全部通过，失败 0 次；活跃及空闲长连接退出码均为 0。全部 45 个应用源码文件与启动快照及 c13f785 提交一致。近端 RSS 最高 83172 KiB、末次 74892 KiB。脱敏证据见 PAIRED-RELAY-RESULTS.json。此前短时预检保留为中断记录，不能与本窗口相加。

## Windows 与原通道边界

已用固定指纹及实际 whoami/hostname 核对原 Windows 电脑。开发组件位于独立 `SSH-Relay-Paired-Debug` 目录，官方 Electron Windows 组件通过固定 SHA-256 校验后解压；这不代表 GUI、自启动或新链路已通过实机验收。

只读观察发现原会话还有另一条新版近端在发包。排查中曾临时更换本任务持有的云端近端，发现共享后恢复原实现，不再用旧共享会话测试新版。没有关闭其他近端或改写原远端/网站目录；原网站可达性本轮未验收，不能声称全程可用。

Windows 开发版的首次独立配对、界面和自启动实际验证仍待完成；用户已被请求启动独立远端并给出一次性配对码。普通旧会话超时不能当成新配对式链路已失败，也不能用云端结果替代 Windows 结果。

## 自启动与交付界限

当前开关实现为用户登录后静默启动，读取操作系统的实际注册状态；不是登录前系统服务。未做整机重启测试，不宣称真实开机通过，不因测试而中断现有业务。

交付包只包含应用、官方运行时/首次准备程序、说明和许可。私钥、配对码、连接报告、导入状态及原始日志留在私密目录，不进入 Git 或 ZIP。最终汇总将仅包含脱敏计数、范围、源码哈希与明确限制。
