MCP SSH Manager 近端使用说明（Codex / Cloudflare Tunnel）
=========================================================

这个文件夹放在运行 Codex 的笔记本上。它让 Codex 通过 Cloudflare Tunnel
连接远端 Windows 10 上的便携 SSH。近端不需要打开 Bash 或命令行。

首次连接
--------
1. 远端 Win10 双击“启动Cloudflare远程SSH.cmd”，等待它打印完整连接包。
2. 复制远端输出中从 MCP_CLOUDFLARE_SSH_BEGIN 到
   MCP_CLOUDFLARE_SSH_END 的全部文字。
3. 回到这台笔记本，保持该连接包在剪贴板中，双击本文件夹里的
   “双击接入Codex.vbs”。
4. 等待提示“Cloudflare SSH 已连接成功”。程序会在后台启动 Cloudflare
   本地代理、用 SSH 密钥实际登录远端，并把服务器配置到当前 Windows
   用户的 Codex 配置中。
5. 打开一个新的 Codex 会话，说：“列出 SSH 服务器”，或“在
   win10_cloudflare 上执行 hostname”。

换 Codex 会话
------------
Codex 的 MCP 和 SSH 服务器配置保存在本机用户配置中，新会话可以继续使用。
本文件夹不会自动把说明文字注入 AI 的对话上下文；如果新会话不知道如何
连接，请让它先阅读本文件夹里的“使用说明.txt”，然后明确告诉它服务器名
是 win10_cloudflare。

远端必须正在运行
----------------
远端 Win10 需保持“启动Cloudflare远程SSH.cmd”启动的窗口/脚本所创建的
sshd 与 cloudflared 进程运行。重启远端电脑或隧道后，Cloudflare Quick
Tunnel 域名可能改变；届时重新复制远端打印的新连接包，并再次双击导入。

停止与恢复
----------
双击“停止本地Cloudflare代理.cmd”可停止笔记本上的本地代理。
再次使用时重新复制远端当前打印的连接包，再双击“双击接入Codex.vbs”。
远端 SSH 隧道需在远端停止；关闭或重启远端 SSH 启动脚本创建的进程即可。

文件说明
--------
双击接入Codex.vbs       无窗口启动近端导入程序
import-cloudflare-ssh.ps1 读取连接包、保存私钥、建立代理、验证 SSH、配置 Codex
runtime\                 随包提供的 cloudflared 和 OpenSSH 客户端
data\                    本机私钥、代理日志、PID 和当前连接包

安全提示
--------
连接包包含 SSH 私钥，只应在你自己的笔记本与远端之间传递；不要公开发布。
私钥只写入本机 data 文件夹，并限制为当前用户和 SYSTEM 可访问。
