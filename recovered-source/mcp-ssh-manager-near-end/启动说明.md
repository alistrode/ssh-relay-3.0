# 近端（Codex 笔记本侧）精简包 · 启动说明

本包是"近端"要跑的东西：MCP SSH Manager 服务端源码 + Cloudflare 隧道接入脚本。
**本包不含**：`node_modules`、缓存日志、`runtime\`（`cloudflared.exe`、`OpenSSH-Win64\ssh.exe`）、`data\`（私钥与连接包）。

## 一、包内结构

```
mcp-ssh-manager-near-end/
├── src/                       MCP 服务端源码（入口 src/index.js）
├── cli/                       命令行工具
├── profiles/                  配置档案
├── package.json               依赖清单
├── package-lock.json          锁文件
├── start-mcp-ssh-manager.cmd  一键启动（Windows）
├── start-mcp-ssh-manager.ps1  一键启动的实际逻辑
├── 启动说明.md                 本文件
└── cloudflare-codex-client/   隧道接入客户端
    ├── 双击接入Codex.vbs        双击入口（无窗口）
    ├── import-cloudflare-ssh.ps1 实际逻辑：读连接包→存私钥→起代理→试登录→写 Codex 配置
    ├── 停止本地Cloudflare代理.cmd 停止本地代理
    ├── 使用说明.txt              隧道接入的完整操作说明
    └── AGENTS.md                目录操作规则（默认把项目工作指向远端）
```

## 二、运行前提

1. Windows + Node.js 18 或更高；Node、Codex CLI（`codex`）都要在 PATH 里。
2. 首次要装依赖：在包根目录执行 `npm ci`（锁文件已包含；没有 `node_modules`，必须联网装）。
3. 隧道还需要两个运行库，本包按要求已移除，请自行补齐：
   - `cloudflare-codex-client\runtime\cloudflared.exe`
   - `cloudflare-codex-client\runtime\OpenSSH-Win64\ssh.exe`（连同该目录其余文件）

## 三、启动 MCP 服务端

双击 `start-mcp-ssh-manager.cmd`（或执行 `pwsh -File .\start-mcp-ssh-manager.ps1`）。它会：
检查 `node`/`codex` → 必要时装依赖 → 确保 `%USERPROFILE%\.codex\ssh-config.toml` 存在 → 注册
`codex mcp add mcp-ssh-manager --env SSH_CONFIG_PATH=... -- <node> <本包>\src\index.js` → 打开交互 CLI。

## 四、接远端（Cloudflare 隧道）

1. 远端 Win10 启动它的 SSH/隧道脚本，等它打印完整连接包。
2. 复制从 `MCP_CLOUDFLARE_SSH_BEGIN` 到 `MCP_CLOUDFLARE_SSH_END` 的全部文字。
3. 回到本机，双击 `cloudflare-codex-client\双击接入Codex.vbs`，等待"Cloudflare SSH 已连接成功"。
4. 新开一个 Codex 会话，说"列出 SSH 服务器"，服务器名是 `win10_cloudflare`。

停止：双击 `cloudflare-codex-client\停止本地Cloudflare代理.cmd`；远端隧道要在远端停。

## 五、注意

- 远端必须保持 sshd 与 cloudflared 在运行，重启远端后 Quick Tunnel 域名会变，需要重新复制连接包再导入。
- 连接包里含 SSH 私钥，只在本机与远端之间传递，不要公开或提交到版本库。
