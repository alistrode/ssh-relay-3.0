# 找回的源码与原始附件

此目录保存从当前云端工作区附件找回的所有文件，未经代码改写。

- `mcp-ssh-manager-near-end/`：原始 JavaScript 源码、CLI、配置模板和启动脚本。
- `portable-ssh-server/`：Windows SSH / Cloudflare 脚本及随附运行组件。
- `original-archives/`：两份原始上传压缩包，完整保留。
- `MANIFEST.json`：上述文件的大小和 SHA-256 校验值。

仓库原有连接脚本和便携包仍保存在 `.agents/skills/` 与 `downloads/`。这些是当前可找到的文件，不能据此断言包含不可访问会话中的所有后续修改。
