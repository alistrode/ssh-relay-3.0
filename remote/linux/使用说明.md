# 一键公网 SSH 远端

完整解压。Linux x64 运行 bash start.sh；Windows 10 x64 双击 START.cmd。已包含官方 Node.js 运行时，不需要管理员权限。

首次启动自动生成独立连接凭据，之后保存在 data/ 并复用；不会使用或修改旧 Cloudflare/OpenSSH 的密钥。将窗口中 SSH_RELAY_CONNECT_BEGIN 到 SSH_RELAY_CONNECT_END 的完整块，交给已安装对应连接技能的新 AI 即可。该块包含访问凭据，请只交给你信任的 AI，勿公开发布。不要将运行后生成的 data/ 提交 Git。

技能：connect-linux-public-ssh 或 connect-win10-public-ssh。技能包必须完整包含 scripts/connect.py 及 assets/near.cjs；新 AI 通过这些文件导入打印块，不需要旧聊天或旧云环境的密钥。近端需要 Python 3.10+、Node.js 22+ 和 OpenSSH 客户端。

程序通过 wss://broker.emqx.io:8084/mqtt 公共测试中继通信，保持 TLS 验证、SSH 公钥认证和固定主机指纹，中继包附有 HMAC。没有入站端口要求。公共中继无可用性保证。支持远程命令和基本 SFTP；不提供 PTY。运行期间保留窗口，关闭即可停止。

本下载包不包含任何预设连接密钥。来源运行时的 SHA256 已核对官方清单。Linux 原生公网测试通过；Windows START.cmd/node.exe 在 Wine 10.0 兼容环境中通过公网测试，尚未进行 Win10 实机测试。Windows 自带 PowerShell 集成需要在真实 Win10 上进一步确认；CMD 和 SFTP 已测试。验证记录见 VALIDATION.json。
